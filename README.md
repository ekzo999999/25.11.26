# Приложение «Приём заявок»

Десктопное приложение для учёта заявок, написанное на Python с использованием библиотеки Tkinter. 
Проект разработан в рамках учебного процесса и включает в себя версионирование, тестирование и поиск дефектов.

## Версии проекта

*   **Версия 0.2.0** — Базовая версия согласно требованиям (счётчик, лимит, сброс, смена статуса, дата).
*   **Версия 0.3.0** — Тестовая версия с внедрением изменения CR-1 (добавлен счётчик закрытых заявок и номер версии в окне). В данной версии намеренно оставлены дефекты для проведения тестирования.

## Функционал

*   **Принятие заявки:** Увеличение счётчика принятых заявок на 1.
*   **Лимит:** Ограничение на приём до 10 заявок включительно. При достижении лимита кнопка блокируется, а текст меняется на «Лимит: 10».
*   **Фиксация времени:** После приёма заявки отображается текущая дата и время в формате `ДД.ММ.ГГГГ ЧЧ:ММ`.
*   **Смена статуса:** Циклическое переключение статуса заявки: `Новая -> В работе -> Готово -> Новая`.
*   **Счётчик закрытых:** Отслеживание количества заявок, переведённых в статус «Готово» (добавлено в v0.3.0).
*   **Сброс:** Обнуление счётчика, даты и возврат кнопки приёма в активное состояние.

## Технологии

*   **Язык программирования:** Python 3.x
*   **Библиотека для GUI:** Tkinter (встроенная в Python)
*   **Модуль для работы с датой:** `datetime` (встроенный в Python)
